# InkVault · Obsidian 功能移植待办（Backlog v1.0）

更新：2026-11-09。来源：用户要求评估可移植的 Obsidian 功能。
定位约束：iPad 伴侣端 + 低功耗（D-01/D-05）+ 原生实现（禁插件 D-02）。
跳过项：Dataview / Excalidraw / Canvas 等插件生态类（与 D-02 冲突且体量不符）。

## 第一梯队（已与用户对齐，建议打包为一个变更实施）

实施顺序建议：大纲 → 标签 → 模板 → 图片粘贴 → 反链。

1. **大纲面板**
   - 侧栏列出当前笔记标题层级，点按跳转
   - 阅读视图与分屏预览均可用
   - 工作量：低
2. **标签体系**
   - 用户 frontmatter 已在用 tags（多行列表）
   - 标签索引（扫描时机：打开库后一次 + 同步完成后一次，前台进行，退场即弃）
   - 标签浏览页 + 按标签过滤文件列表
   - 工作量：中
3. **模板系统**
   - 模板目录（默认 `templates/`，读 `.obsidian` 配置对齐用户习惯）+ `{{date}}` `{{time}}` `{{title}}` 变量
   - **每日笔记支持指定模板文件**（用户 frontmatter 工作流：create 字段）
   - 工作量：低
4. **图片粘贴插入**
   - iPad 截图 → 编辑器粘贴 → 存附件目录 → 插入 `![[文件名]]`
   - 附件目录**读取 `.obsidian/app.json` 的 attachment 配置**（只读，对齐 Obsidian 习惯，合规 D-04）
   - 工作量：中
5. **反链/出链（Backlinks）**
   - 打开笔记时惰性扫描库内 `[[链接]]` 建索引（前台、会话级缓存、退场即弃，符合 NFR-03）
   - 笔记底部显示「反向链接」区块 + 侧栏出链列表
   - 工作量：中

## 第二梯队（按需排期）

- 局部图谱：当前笔记出链+反链两层关系图（原生 SVG）；全图谱太重不做
- 最近文件 + 书签
- 导出分享：单篇 PDF / Markdown 系统分享面板
- 快速切换器模糊匹配：⌘O 升级为拼音/模糊评分（当前为子串匹配）
- 编辑增强：列表自动续行、智能括号（可开关）
- 显示设置：字号、行距、深浅色跟随

## 第三梯队（锦上添花）

- 快捷指令（Shortcuts）App Intent：「追加到每日笔记」系统级随手记
- iPad 拖拽：从其他 App 拖图片/文件进编辑器
- 软件键盘工具条：Tab/方向键/markdown 符号（补无外接键盘时的 vim 体验）

## 已落地（避免重复实现）

- 快速搜索浮层 ⌘O / ⌥O（文件名+内容，子串匹配）
- 新建笔记 ⌘N（重名自动序号）、每日笔记 ⌘J（自动带 create frontmatter）
- 三态查看模式（阅读/编辑/分屏实时预览，400ms 防抖）
- Mermaid/KaTeX 离屏渲染、frontmatter 属性表（含多行列表归并、CRLF 归一）
